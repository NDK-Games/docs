## Definition of Ready

Перед стартом текущего спринта и добавлением задач:

- [ ] Цель задачи понятна.
- [ ] Рабочий план для Product Owner записан простым языком.
- [ ] Командный план показывает owner, роли, последовательные шаги, параллельные работы, handoff и проверки.
- [ ] Для всех шести этапов назначены owner, результат и критерий завершения.
- [ ] Целевой канал и критерий завершения публикации определены.
- [ ] Для измеримых продуктовых изменений определены baseline, метрика успеха и доступный источник данных.
- [ ] Есть owner.
- [ ] Есть связь с requirement, roadmap или профильным документом-владельцем.
- [ ] Понятны acceptance criteria или способ проверки.
- [ ] Известны основные зависимости и риски.

## Definition of Done

Перед закрытием текущего плана:

- [ ] Требования выполнены.
- [ ] Аналитика завершена, цель, исходные данные и ожидаемый результат зафиксированы.
- [ ] Планирование завершено, отклонения scope зафиксированы.
- [ ] Разработка и review завершены.
- [ ] Тесты и ручные проверки пройдены.
- [ ] Баги P0/P1 закрыты или явно приняты.
- [ ] Публикация достигла проектного критерия завершения.
- [ ] Итоговый отчет принят и сохранен в roadmap или связан с ним.
- [ ] Незавершенная работа явно перенесена в backlog / следующий план.
- [ ] Документация обновлена.
- [ ] Post-publication и применимые операционные проверки выполнены.
