# Типы проектов

Общие документы `00-context/`–`06-history/` используются для всех проектов. Здесь находятся дополнения, содержание которых зависит от типа продукта.

| Тип | Процесс | Специальный документ продукта |
| --- | --- | --- |
| Мобильная игра (`game`) | [17 этапов разработки и развития](games/GAME_LIFECYCLE.md) | [Дизайн игры](games/GAME_DESIGN.md), [стандарт экранов](games/GAME_SCREENS.md) |
| Сервис (`service`) | [Существующий регламент из 18 этапов](../02-team/process/SERVICE_LIFECYCLE_REGULATION.md) | Общие требования и сценарии |
| Веб-проект или другой продукт | Отдельный профиль будет добавлен позднее; для веб-сервиса можно явно выбрать процесс сервиса | Определяется при выборе процесса |

В [PROJECT.md](../01-product/strategy/PROJECT.md) указать тип и один основной регламент. В [STATE.md](../01-product/strategy/STATE.md) заполнить реестр его этапов. Цель, текущий план, требования и отчёты вести в существующих документах по [карте владельцев фактов](../00-context/DOCS.md#source-of-truth).

Для нового типа добавить отдельную папку с регламентом и только теми специальными документами, которых нет в общем ядре. Обновить эту таблицу и карту документации. Игровые этапы применяются только к играм.
