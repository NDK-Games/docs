# Игровой профиль

**Область применения: только игры.** Текущая редакция описывает мобильные игры для Android / Google Play и iOS / App Store. Для других игровых платформ требуется явная адаптация. Для веб-сайтов, обычных приложений и других продуктов этот профиль не применяется.

## Правила использования

В экземпляре документации игры выбрать тип `game` и этот регламент в общем [PROJECT.md](../../01-product/strategy/PROJECT.md). Подготовить постановку по шаблону цели и создать реестр в общем [STATE.md](../../01-product/strategy/STATE.md). Пошаговая инструкция находится в [PROJECT_SETUP.md](PROJECT_SETUP.md).

После каждого этапа агент передаёт проверяемый результат и останавливается. Следующий этап начинается после явного принятия результата пользователем и разрешения перехода. Если пользователь принял результат, но не разрешил продолжение, переход остаётся закрытым. Замечания исправляются в текущем этапе.

Этапы 1–14 завершаются выпуском рабочей версии. Этапы 15–17 выполняются за заранее согласованные периоды и бюджеты. Завершение одного цикла не разрешает бесконечную аналитику, эксперименты или продвижение. Повторный цикл требует нового решения.

Игровой регламент заменяет для выбранной игры 18-этапный регламент сервиса. Общая структура фактов, роли, задачи, спринты и проверки продолжают использоваться. Старый трёхэтапный комплект хранится для истории и не задаёт условия завершения или разрешения текущего процесса.
