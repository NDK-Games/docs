# Документация игры

Только для мобильных игр Android / Google Play и iOS / App Store. Для других игровых платформ требуется адаптация; для неигровых проектов эти документы не применяются.

- [GAME_LIFECYCLE.md](GAME_LIFECYCLE.md) — все 17 этапов от концепта до публикации и развития, работы, результаты и обязательная проверка пользователя после каждого.
- [GAME_DESIGN.md](GAME_DESIGN.md) — правила конкретной игры: основной цикл, механики, прогрессия, контент, баланс, визуальный стиль и звук. В экземпляре проекта заполняется этот файл.

Цель и полномочия хранятся в общем [PROJECT.md](../../01-product/strategy/PROJECT.md), статусы и решения пользователя — в [STATE.md](../../01-product/strategy/STATE.md). Остальные материалы распределяются по общей [карте документации](../../00-context/DOCS.md#source-of-truth); второй комплект планов и правил создавать не нужно.

Пример короткой постановки: «Создай [название игры] для [платформы], выпусти рабочую версию и выполни один согласованный цикл развития по GAME_LIFECYCLE.md. После каждого этапа передавай результат на мою проверку и жди явного разрешения следующего». Границы результата, периоды и бюджет записываются в `PROJECT.md`.
