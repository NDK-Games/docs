Будущие этапы остаются `todo`. Передача пользователю — `review`; замечания — `doing` с состоянием «На доработке». `done` означает принятие пользователем точной версии. Принятие не заполняет автоматически поле разрешения следующего этапа. Ожидание пользовательской проверки обозначается `review`, внешняя непреодолённая зависимость — `blocked`.
