# Обязательные экраны и общие функции игры

Единый стандарт интерфейса для мобильных игр Android и iOS. Помогает быстро проверить состав полной версии: от загрузки и главного меню до наград, настроек и ошибок. Владелец стандарта — Product Owner.

**Обязательно** — входит в каждую игру. **По условию** — обязательно при указанной функции. **Опционально** — добавляется по решению проекта. Окно или панель могут заменять отдельный экран, если сохраняют весь нужный функционал.

Стандарт применяется к полной версии; системы подключаются на своих этапах по [GAME_LIFECYCLE.md](GAME_LIFECYCLE.md). Прототип проверяет механику и не требует всего набора.

## Экраны и окна

| Экран | Статус | Минимальное содержимое |
| --- | --- | --- |
| Загрузка | Обязательно | Название или логотип, состояние загрузки, ссылки **Terms of Use** и **Privacy Policy**; при сбое — понятная причина и повтор |
| Первый вход | Обязательно | Короткое обучение основному действию; пройденные шаги сохраняются |
| Согласия и разрешения | По условию | Показывать перед действием или обработкой данных, которым нужно разрешение; учитывать отказ |
| Главное меню | Обязательно | Играть / Продолжить, настройки, магазин, прогресс, достижения и рейтинги |
| Игровой экран | Обязательно | Цель, нужные ресурсы, прогресс, управление и доступ к паузе |
| Пауза | Обязательно | Продолжить, настройки, выход в меню; повтор — если применим, с предупреждением о потере попытки |
| Результат | Обязательно | Итог эпизода, полученные награды, следующий шаг; при проигрыше — повтор или выход |
| Магазин | Обязательно | Доступные товары, цена, баланс, результат покупки и закрытие; покупки за реальные деньги — по модели проекта |
| Настройки | Обязательно | Состав из таблицы ниже; доступны из меню и паузы |
| Достижения | Обязательно | Условия, прогресс, выполненные цели; награды — если предусмотрены |
| Рейтинги | Обязательно | Таблица, правило сравнения, результат игрока; вход в сервис и состояния без сети / результатов |
| Daily Reward | Опционально | Автоматическое окно ежедневной награды при входе; отдельная кнопка в меню не нужна |
| Time Reward | Опционально | Прогресс до награды за активное время игры и получение доступной награды |

Ссылки на Terms of Use и Privacy Policy доступны также в настройках: загрузка может закончиться раньше, чем игрок успеет их открыть. При открытом тексте автоматический переход не закрывает его. Наличие ссылки не заменяет отдельное согласие, когда оно требуется.

## Состав главного меню

| Элемент | Статус | Расположение и поведение |
| --- | --- | --- |
| Играть / Продолжить | Обязательно | Основное заметное действие; ведёт к текущему уровню или доступной активности |
| Прогресс | Обязательно | Текущий уровень, глава или рекорд — согласно типу игры |
| Currency View | По условию — есть валюты | Сверху: иконка и баланс каждой основной валюты; обновление сразу после выдачи или траты |
| Переход в магазин | Обязательно | Кнопка «Магазин» либо явный «+» у валюты; «+» открывает соответствующий раздел |
| Настройки | Обязательно | Постоянно доступная узнаваемая кнопка |
| Достижения и рейтинги | Обязательно | Две кнопки или один раздел с двумя понятными вкладками; возможен платформенный интерфейс |
| Time Reward | Опционально | Компактный таймер или иконка; отметка, когда награда доступна |
| События и предложения | Опционально | Ограниченное число вторичных элементов; закрываемые окна после основных действий входа |

Магазин доступен уже из главного меню. При нехватке валюты показываются недостающая сумма и явный переход к нужному предложению; покупка сама не запускается.

## Состав настроек

| Пункт | Статус | Что должно работать |
| --- | --- | --- |
| Музыка | По условию — есть музыка | Отдельное вкл / выкл; если музыки в игре нет, пункт скрыт |
| Звуковые эффекты | Обязательно | Отдельное вкл / выкл; выбор не меняет музыку |
| Вибрация | По условию — используется | Вкл / выкл на поддерживаемых устройствах |
| Язык | По условию — несколько языков | Язык устройства по умолчанию и ручной выбор; язык сохраняется |
| Доступность | По условию — есть такие эффекты | Отключение тряски и уменьшение интенсивных анимаций |
| Уведомления | По условию — используются | Управление напоминаниями; учитывать системный запрет и дать переход в настройки ОС |
| Аккаунт и сохранение | По условию — есть аккаунт / облако | Статус входа и синхронизации, вход / выход; смена аккаунта не смешивает прогресс |
| Восстановить покупки | По условию — есть восстанавливаемые покупки | Восстановление прав, например удаления рекламы; результат и ошибка видны игроку. [Apple 3.1.1](https://developer.apple.com/app-store/review/guidelines/#in-app-purchase) |
| Конфиденциальность | По условию — нужны согласия | Повторное открытие управления согласиями; для системных разрешений — переход в ОС |
| Terms of Use и Privacy Policy | Обязательно | Две читаемые, работающие ссылки. Доступность политики в приложении предусмотрена [Apple 5.1.1](https://developer.apple.com/app-store/review/guidelines/#data-collection-and-storage) и [Google Play](https://support.google.com/googleplay/android-developer/answer/10144311?hl=en) |
| Удалить аккаунт | По условию — можно создать аккаунт | Доступный запуск удаления с объяснением последствий и подтверждением; локальный сброс не заменяет удаление. [Apple](https://developer.apple.com/app-store/review/guidelines/#data-collection-and-storage), [Google Play](https://support.google.com/googleplay/android-developer/answer/10144311?hl=en#account_deletion) |
| Помощь и поддержка | Обязательно | Короткая справка и рабочий способ обратиться в поддержку |
| Версия игры | Обязательно | Номер версии и сборки; ID игрока — если используется поддержкой |
| Сбросить прогресс | Опционально | Отдельное подтверждение с перечнем удаляемых данных; права на покупки сохраняются |

Выбор настроек применяется сразу и сохраняется после перезапуска. Для удалённого в ОС разрешения интерфейс показывает реальное состояние. Восстановление покупок не обещает повторную выдачу уже потраченной валюты. Для Google Play при создании аккаунта нужен также внешний веб-способ запросить удаление — по [правилам User Data](https://support.google.com/googleplay/android-developer/answer/10144311?hl=en#account_deletion).

## Daily Reward

Если функция включена, используются следующие правила по умолчанию. Размеры наград и изменения правил фиксируются в дизайне конкретной игры.

| Правило | Поведение |
| --- | --- |
| Цикл | 7 дней или больше; видна вся последовательность, текущий день и финальная награда |
| Первая награда | Доступна после вводного обучения, при первом попадании в меню |
| Следующая награда | Через **24 часа после получения предыдущей**; пример: получил в 15:00 → следующая доступна не раньше 15:00 следующего дня |
| Показ | Автоматически при входе в меню после запуска или возвращения из фона, если награда доступна; без отдельной кнопки Daily Reward |
| Закрытие без получения | Награда остаётся доступной; окно повторяется при следующем входе в игру, не при каждом возврате в меню |
| Получение | Кнопка «Забрать» выдаёт награду один раз; день цикла и баланс сохраняются вместе |
| Пропущенные дни | Прогресс цикла сохраняется; пропущенное время не выдаёт несколько наград сразу |
| Конец цикла | Последний день даёт наиболее ценную награду; после получения цикл начинается заново с обычным ожиданием 24 часов |
| Реклама | Базовая награда бесплатна; добровольное увеличение за рекламу допустимо только как отдельная опция |

Один день цикла означает одну полученную награду. Календарная полночь не сбрасывает ожидание. Такая схема мотивирует возвращаться минимум семь раз; число фактически последовательных календарных дней не является условием выдачи.

## Time Reward

| Правило | Поведение при включённой функции |
| --- | --- |
| Что считаем | Активное время игрового процесса; фон, пауза, меню и просмотр рекламы не учитываются |
| Порог | Определяется балансом; простой стартовый вариант — одна награда за каждые 10 минут активной игры |
| Прогресс | Сохраняется между сессиями; после порога ожидание получения останавливает таймер, награды не копятся бесконечно |
| Получение | Игрок забирает награду в меню; затем начинается следующий интервал |
| Подача | Видны оставшееся время, награда и состояние «Забрать»; окно не прерывает игровой эпизод |

Награды и интервалы должны поддерживать экономику игры. Числовой баланс хранится в одном источнике в [GAME_DESIGN.md](GAME_DESIGN.md) или связанном файле конфигурации.

## Порядок входа и общие состояния

Обычный вход: **загрузка → необходимые согласия → главное меню → Daily Reward при доступности → свободное действие игрока**. При первом входе обучение проходит до наград. Системные разрешения запрашиваются в контексте соответствующей функции; ATT на iOS применяется при отслеживании, как определено в [правилах Apple](https://developer.apple.com/app-store/user-privacy-and-data-use/).

| Ситуация | Обязательное поведение |
| --- | --- |
| Несколько окон при входе | Одно окно за раз; обязательные действия раньше бонусов, предложения после них; после закрытия доступна кнопка «Играть» |
| Нет сети | Доступные локальные режимы работают; у сетевых функций — сообщение и повтор, без бесконечной загрузки |
| Долго грузится или произошла ошибка | Понятный статус и действие: повторить, вернуться или продолжить локально, если допустимо |
| Закрытие и системный Back | Понятный возврат; сначала закрывается верхнее окно, затем выполняется выход из экрана |
| Фон или перезапуск | Прогресс и настройки сохранены; возвращение в активный эпизод через паузу или отсчёт |
| Повторное нажатие или сбой при выдаче | Одна покупка / награда начисляется один раз; после восстановления нет потери подтверждённой выдачи |
| Смена времени устройства | Суточные награды проверяются по доверенному времени; локальные часы не считаются надёжными. Офлайн-режим и его ограничения определяются в GDD |
| Покупка или реклама недоступны | Цена не подменяется; есть отмена / закрытие; за неудавшийся просмотр награда не обещается как полученная |
| Разные устройства и языки | Учтены вырезы экрана, длинные переводы, читаемые кнопки; элементы не перекрываются, важная информация различима не только по цвету |

## Дополнения по решению проекта

| Функция | Когда добавлять |
| --- | --- |
| Ежедневные задания | Есть несколько осмысленных игровых действий и ресурсы на баланс заданий |
| Карта уровней / коллекция | Нужен самостоятельный выбор контента или просмотр собранных предметов |
| События / сезонные награды | Есть контент и поддержка регулярных обновлений |
| Оценить игру / поделиться | После завершённого эпизода, без награды за отзыв; оценка необязательна |
| Убрать рекламу / подписка | Предусмотрено моделью монетизации; доступ из магазина, понятный состав предложения |
